# AI Elementor Addon

This repository contains a custom WordPress plugin that extends Elementor with AI-powered widgets. The addon introduces unique widgets that integrate with OpenAI and can be toggled individually from the WordPress admin area.

## Features

- **AI Chat Assistant** – Embed conversational AI experiences that inherit Elementor styling controls.
- **AI Brainstorm Canvas** – Generate structured ideas and outlines based on visitor topics.
- **AI Image Prompt Mentor** – Help users craft detailed prompts for image generation workflows.
- **Admin Controls** – Dedicated pages for dashboard overview, widget toggles, OpenAI configuration, and roadmap planning.
- **AJAX Integration** – Secure bridge between Elementor widgets and the OpenAI Responses API.

## Getting Started

1. Copy the `ai-elementor-addon` directory into your WordPress installation’s `wp-content/plugins/` folder.
2. Activate **AI Elementor Addon** from the Plugins screen.
3. Visit **AI Elementor → OpenAI Settings** to provide your API key and preferred model.
4. Use **AI Elementor → Widget Manager** to enable or disable widgets before adding them to Elementor pages.

All widgets leverage Elementor’s native design controls, so you can style typography, spacing, colors, and borders using familiar UI panels.
